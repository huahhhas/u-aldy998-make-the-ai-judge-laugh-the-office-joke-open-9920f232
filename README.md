# The Office Printer Joke

One line of office comedy, at most 200 characters — a printer that can't print, but still finds a way to file a report about it.

> The office printer ran out of ink, so it printed a 12-page error report explaining why it can't print.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (or to the path in `MAKEFUN_OUTPUT_DIR`).
